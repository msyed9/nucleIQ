# NucleiQ - Keyboard Shortcuts Reference

## Global Shortcuts

| Shortcut | Action | Component |
|----------|--------|-----------|
| `Ctrl + /` | Open Global Search | GlobalSearch |
| `Ctrl + K` | Open Quick Actions | QuickActions |
| `ESC` | Close Dialogs | All Dialogs |
| `↑` `↓` | Navigate Results | Search/Lists |
| `Enter` | Select Item | Search/Lists |

## Quick Actions Shortcuts

| Shortcut | Action | Module |
|----------|--------|--------|
| `Ctrl + Shift + S` | Add Student | Students |
| `Ctrl + Shift + F` | Collect Fee | Finance |
| `Ctrl + Shift + A` | Mark Attendance | Attendance |
| `Ctrl + Shift + E` | Schedule Exam | Exams |
| `Ctrl + Shift + M` | Send Message | Communication |

## Navigation Tips

1. **Quick Search**: Press `Ctrl+/` from anywhere to search
2. **Quick Actions**: Press `Ctrl+K` to access frequently used actions
3. **Favorites**: Star your most-used actions for quick access
4. **Recent Searches**: Your last 5 searches are saved automatically
5. **Dashboard Layouts**: Switch between Default, Compact, and Detailed views

## Power User Tips

- Use keyboard shortcuts to navigate 10x faster
- Customize your dashboard widgets for your role
- Set up favorite quick actions for one-click access
- Use filters in tables to find data quickly
