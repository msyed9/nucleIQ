## 💡 **Usage Guide**

- Organized by category
- Click any template to load

### **Step 2: Add Elements**
- Use toolbar buttons:
  - 📝 Text
  - 🖼️ Image
  - ⬜ Shape
  - 📱 QR Code
  - 📊 Barcode

### **Step 3: Edit Elements**
- Click element to select
- Drag to move
- Resize from corners/edges
- Edit properties in right panel

- Change background color
- Modify text content
- Adjust colors and sizes
- Use placeholders

- Enter design name
- Click "💾 Save Design"
- Design saved to database
