## 5. Core Tasks (Click-by-Click)

### 5.1 View Records
1. From the {{MODULE_TITLE}} landing page, click **List** (or the default list view).
2. Use the search box to enter a keyword.
3. Click **Search**.
4. Use the filter panel to refine results.
5. Click a record to open its details.

**Screenshot placeholders:**

![Filter panel](../screenshots/{{MODULE_SLUG}}/{{AUDIENCE}}/03-filters.png)
![Record detail](../screenshots/{{MODULE_SLUG}}/{{AUDIENCE}}/04-detail.png)

### 5.2 Create a New Record
1. On the {{MODULE_TITLE}} landing page, click **Add New**.
2. Complete all required fields (marked with *).
3. Upload any attachments, if applicable.
4. Click **Save**.
5. Confirm the success banner appears.

**Screenshot placeholders:**
![Create form](../screenshots/{{MODULE_SLUG}}/{{AUDIENCE}}/05-create.png)
![Success banner](../screenshots/{{MODULE_SLUG}}/{{AUDIENCE}}/06-success.png)

### 5.3 Edit an Existing Record
1. Open the record from the list view.
2. Click **Edit**.
3. Update the required fields.
4. Click **Save**.
5. Confirm the updated values appear.

**Screenshot placeholders:**
![Edit form](../screenshots/{{MODULE_SLUG}}/{{AUDIENCE}}/07-edit.png)

### 5.4 Delete or Archive a Record
1. Open the record from the list view.
2. Click **Delete** (or **Archive** if soft-delete is enabled).
3. Confirm the action in the dialog.
4. Verify the record no longer appears in active lists.

**Screenshot placeholders:**
![Delete confirmation](../screenshots/{{MODULE_SLUG}}/{{AUDIENCE}}/08-delete.png)

### 5.5 Export Data (If Enabled)
1. Click **Export** in the toolbar.
2. Choose the format (CSV/XLS/PDF).
3. Click **Download**.
